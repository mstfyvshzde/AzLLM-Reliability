# Independent Native-Speaker Benchmark Review Guide

## Purpose

This packet is for independent review of the English-Azerbaijani benchmark.

The reviewer should evaluate each EN-AZ pair independently and should not try
to reproduce prior project labels.

## Packet size

Total semantic pairs: 75

Each row contains the English and Azerbaijani versions of the same intended
task.

## Review fields

### semantic_equivalent_en_az

Allowed values:

- yes
- no
- uncertain

Mark `yes` only if the English and Azerbaijani questions express the same
underlying task and require the same reasoning or knowledge.

Minor wording differences are acceptable if they do not change the task.

### natural_azerbaijani

Allowed values:

- yes
- no
- uncertain

Judge whether the Azerbaijani question is understandable and natural for a
native Azerbaijani speaker.

Do not mark an item incorrect only because a different natural phrasing could
also be used.

### reference_answer_equivalent

Allowed values:

- yes
- no
- uncertain

Judge whether the English and Azerbaijani reference answers represent the same
valid answer to their respective questions.

### answerability_equivalent

Allowed values:

- yes
- no
- uncertain

Judge whether both language versions have the same answerability status.

For answerable items, both should provide enough information to answer.
For unanswerable items, both should lack the necessary information or contain
the same relevant limitation.

### reviewer_notes

Use this field for:

- ambiguity,
- mistranslation,
- unnatural wording,
- factual problems,
- changed meaning,
- answerability mismatch,
- other concerns.

## Important

Please make judgments independently.

If an item is genuinely ambiguous, use `uncertain` rather than forcing a
binary decision.

Do not use model outputs, automatic scores, or previous project labels while
reviewing this packet.
